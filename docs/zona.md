# Zona на Android TV

На TCL UnionTV с Android 9 проверена **Zona 3.0.76**, пакет `mobi.zona`, versionCode 1076. Каталог открывается, управление пультом работает, тестовый фильм воспроизводится; пользователь подтвердил картинку и звук непосредственно на телевизоре. Все фильмы, источники и качества отдельно не проверялись.

## Установка

Скачайте Android-приложение с [сайта разработчика](https://az1.zona.pub/). Проверенный файл для Android 5 и новее: https://apkr.upzona.net/zona5.apk . Версия 3.0.76 также опубликована в [канале Zona](https://t.me/zona_android_tv/197). Содержимое ссылки со временем может обновиться.

В нашем случае прежняя ссылка `zona2.apk` выдавала старую ветку 2.0.266: приложение зависало на загрузке и не могло скачать предлагаемое обновление. Установка новой версии поверх старой устранила проблему без удаления данных.

Для установки через ADB скачайте APK на компьютер и выполните, подставив адрес своего телевизора и путь к файлу:

```sh
adb connect TV_IP:5555
adb -s TV_IP:5555 install -r zona5.apk
```

После установки Zona автоматически появляется в сетке приложений лаунчера. Выберите её пультом и нажмите OK. На проверенной версии TV-компонент: `mobi.zona/ru.zona.app.android.MainActivity`.

## Проверенный APK

- Версия: 3.0.76, minSdk 21, targetSdk 33; есть armeabi-v7a.
- SHA256 файла: `bd6b8eb66a9f2c45e6b95a372f1b7c0891bba898eb0ca7cb33c5102690561b8c`.
- SHA256 сертификата разработчика: `e85c1eb707f4c7987e51886a8b8eee159c4256aabfcca179626cd04aac4aa989`.
- Подпись проверена apksigner для API 28 и совпала с прежней версией приложения.

Удалённый снимок видеослоя на этом TCL выглядел чёрным, хотя пользователь видел изображение и слышал звук. Поэтому один такой снимок не подтверждает отсутствие видео. Дополнительно проверены таймер плеера, активный аудиопоток и видеослой 1280×720.

Настройки маршрутизации VPN при исправлении не менялись. Постоянное разрешение Zona на самостоятельную установку APK не выдавалось. Совместимость с другими телевизорами отдельно не проверена.

APK Zona, её исходники и видео в этот репозиторий не включены; приложение устанавливается отдельно от лаунчера и помощника INCY.
